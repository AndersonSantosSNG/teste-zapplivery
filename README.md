# Zapplivery

Site institucional estático da Zapplivery.

## Estrutura

- `index.html`: página inicial.
- `solucoes.html`: soluções Entregas, Field e Pickup.
- `como-funciona.html`: etapas da rastreabilidade.
- `aplicacoes.html`: mercados e integrações.
- `contato.html`: formulário de contato.
- `assets/css`: estilos compartilhados.
- `assets/js`: interações do site.
- `assets/images`: logos, capturas do sistema e fotografia.

Abra `index.html` no navegador para visualizar o projeto.
